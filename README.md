A Node program that writes one line of wedding vows for a robot couple: the classic "in sickness and in health" promise rebuilt from safe mode, low battery and airplane mode, closing with a vow never to trade the beloved in for a newer model. The line is written to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```sh
node main.ts
```
